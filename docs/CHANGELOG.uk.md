## 0.1.2 — 26 липня 2026

- зменшено відступи між доменами в користувацьких списках;
- на сторінку VirusTotal додано офіційне посилання для отримання API-ключа;
- актуалізовано інтерфейс і переклади для російської, української, англійської та німецької мов;
- синхронізовано інсталятор Windows, портативну збірку та пакет Debian.

## 0.1.1 — 26 липня 2026

- адреси на сторінці підтримки можна виділяти й копіювати через контекстне меню;
- видалено непрацюючі кнопки копіювання;
- перевірку оновлень переведено на GitHub Contents API.

## 0.1.0 — 26 липня 2026

- перший публічний випуск для Windows x64 і Debian/Ubuntu amd64;
- очищення URL, локальні бази загроз, користувацькі списки, аналіз перенаправлень;
- необов’язкова перевірка через VirusTotal, робота в треї, проксі та чотири мови.
